# DecodeLabs – Project 2: Exploratory Data Analysis (EDA)

## Project Overview
This project explores a cleaned order dataset to identify patterns, trends, distributions, and unusual values. The goal is to understand the data and communicate useful observations through descriptive statistics and analysis.

## Dataset Overview
- **Records:** 1,200 orders
- **Columns:** 14
- **Date range:** January 2023 – June 2025

## Analysis Performed
- Summary statistics, including mean, median, and count
- Product-wise order analysis
- Order-status distribution
- Monthly order trends
- Referral-source and payment-method analysis
- Coupon-code distribution
- Outlier detection using the IQR method
- Correlation analysis

## Key Findings
- The dataset contains 1,200 orders from 1,189 unique customers.
- The mean order value is 1,053.97.
- The median order value is 823.62.
- Eight high-value outliers were identified using the IQR method.
- Order counts decreased from 2023 to 2024.
- Quantity and unit price both show a positive relationship with total order value.

## Important Note
The reported total order value includes all order statuses, including cancelled, returned, and pending orders. It should not be interpreted as completed sales or revenue.
